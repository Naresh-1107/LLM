LLM stands for Large Language Model.

It is an AI model trained on large amounts of text to understand and generate human-like language.

Normally, when you use ChatGPT, your request goes to a remote server where the model generates a response.

With a local LLM, the model runs on your own computer.

| Local LLM | API-based LLM |
|---|---|
| Runs on your computer | Runs on remote servers |
| Download model required | Internet required |
| Uses local resources | Uses provider resources |
| Can work offline | Usually requires internet |
| No per-request API charge | Pricing depends on provider |

Why uv?

It helps manage Python projects, dependencies and virtual environments.

Ollama allows you to download and run open models locally.
